# Elenco e Membros
{: .no_toc }

Esta seção cobre duas coisas relacionadas mas distintas:

- **Elenco** — os atletas cadastrados no clube (podem existir sem um usuário vinculado)
- **Membros** — os usuários que têm conta no app e solicitaram entrada no clube

Um usuário aprovado fica vinculado a um atleta do elenco.
