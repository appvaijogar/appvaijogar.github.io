## Como funciona o convite

Cada clube tem um **código de convite** único de 8 caracteres (ex.: `a1b2c3d4`). Qualquer pessoa com esse código pode solicitar entrada no clube.

{: .important }
> O código de convite **não aprova ninguém automaticamente** — a entrada fica pendente até um Admin aprovar. Você tem controle total sobre quem entra.

---

## Onde encontrar o código de convite

**Opção 1 — Na tela Meus Clubes:**
- O código aparece logo abaixo do nome do clube.
- Clique no código para **copiar o link de convite** completo.

**Opção 2 — Dentro do clube:**
- No cabeçalho do clube, clique no ícone de link (🔗).
- O link é copiado automaticamente para a área de transferência.

## Compartilhando o convite

Após copiar o link, envie para os jogadores pelo WhatsApp, Telegram ou qualquer outro canal.

O link tem o formato:
```
https://vaijogar.app/join/A1B2C3D4
```

Quando o jogador clicar no link:
1. O app abre já na tela de entrada do clube.
2. O código é preenchido automaticamente.
3. O jogador clica em **Entrar** — a solicitação é enviada.
4. Você recebe a solicitação no painel de **Membros**.

---

## O que o jogador vê após solicitar entrada

Na tela **Meus Clubes**, o clube aparece com o status **"Aguardando Aprovação"** — o jogador não consegue acessar o clube até você aprovar.

---

## Aprovando os membros

Com as solicitações recebidas, vá para o painel do administrador e aprove cada jogador:

[Aprovar Membros →](../elenco/aprovar-membros)

---

## Renovar o código de convite

Por enquanto, o código de convite é fixo. Se você quiser restringir novas entradas, basta **não compartilhar** o código com novas pessoas — as solicitações já feitas continuam pendentes para aprovação.
