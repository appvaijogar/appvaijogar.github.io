## Passo a passo

1. Faça login no app e acesse a tela **Meus Clubes**.
2. Clique em **Criar Clube** (canto inferior esquerdo).
3. O formulário de criação aparece na tela.
4. Digite o **nome do clube** (ex.: *Galáticos FC*, *Pelada de Quinta*).
5. Clique em **Criar Clube**.

## O que é criado automaticamente

Ao criar o clube, o app configura tudo para você já começar a usar:

| Item criado | Detalhe |
|------------|---------|
| **Clube** | Com o nome informado e um código de convite gerado automaticamente |
| **Temporada inicial** | Chamada *"Temporada Inicial [ano atual]"*, já ativa |
| **Seu atleta** | Criado com o seu nome de usuário, status Mensalista |
| **Seu perfil de Admin** | Você vira o administrador do clube automaticamente |

---

## Após criar o clube

O app te leva direto para o painel do clube. Você já pode:

- Compartilhar o código de convite com os jogadores → [Convidar Membros](convidar-membros)
- Cadastrar atletas manualmente → [Cadastrar Atletas](../elenco/cadastrar-atletas)
- Ajustar as configurações do clube → [Configurações](../configuracoes/configuracoes)

{: .tip }
> Você pode criar quantos clubes quiser com a mesma conta. Basta voltar à tela **Meus Clubes** e repetir o processo.
